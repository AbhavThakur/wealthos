# Development & Code Quality Guidelines

## Code Quality & Architecture
- Maintain modular, clean, and idiomatic code.
- Prioritize clear error handling and type safety.
- Write modern, responsive UI with clean CSS/styling and zero boilerplate.
- Avoid obsolete dependencies or unnecessary heavy packages.

## Performance & Dev Experience
- Ensure sub-millisecond hot reloading and clean build outputs.
- Test changes thoroughly before marking complete.
